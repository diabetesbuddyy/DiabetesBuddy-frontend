    ทำไมต้องนับคาร์บ?

    การนับคาร์บช่วยให้ผู้ป่วยเห็นปริมาณคาร์โบไฮเดรตของแต่ละมื้อและนำข้อมูลไปใช้ร่วมกับแผนการรักษาที่ทีมดูแลกำหนด

    เนื้อหานี้เป็นข้อมูลประกอบการเรียนรู้ ควรให้ทีมพยาบาล/แพทย์ตรวจทานก่อนใช้งานจริง

      ประวัติอินซูลิน

        กรุณากรอกน้ำหนักตัว

        แผน Basal ของคุณต้องใช้น้ำหนักตัว แต่ข้อมูลน้ำหนักที่คุณกรอกจะยังไม่ถูกนำไปคำนวณจนกว่าทีมแพทย์ที่ดูแลจะยืนยันรับข้อมูล

        Diabetes Buddy • การคุ้มครองข้อมูลส่วนบุคคล

        🔐 การรับทราบและให้ความยินยอม

        ก่อนใช้ฟังก์ชันของ Diabetes Buddy ระบบต้องขอให้คุณอ่านและรับทราบว่ามีการเก็บ ใช้ และแบ่งปันข้อมูลใดภายในระบบตามบทบาทผู้ใช้งาน

        📌 ข้อมูลที่ระบบอาจเก็บ

        • ข้อมูลบัญชี LINE ที่ใช้ยืนยันตัวตน เช่น LINE User ID และชื่อที่แสดง
        • ข้อมูลสุขภาพที่คุณบันทึก เช่น ค่าน้ำตาลในเลือด เวลาและช่วงเวลาที่ตรวจ
        • ข้อมูลอาหารและคาร์โบไฮเดรตที่คุณบันทึก
        • ข้อมูลแผนอินซูลินที่ทีมแพทย์กำหนด และข้อมูลน้ำหนักที่ใช้ประกอบการดูแล
        • ประวัติการใช้งานที่จำเป็นต่อการตรวจสอบ เช่น การเปลี่ยนแผนและการให้ความยินยอม

        👥 ใครสามารถเข้าถึงข้อมูล

        ผู้ป่วย — เข้าถึงข้อมูลและประวัติของตนเอง
        แพทย์ผู้ดูแล — เข้าถึงข้อมูลของผู้ป่วยที่ได้รับมอบหมาย และจัดการแผนการรักษาตามสิทธิ์
        พยาบาลผู้ดูแล — เข้าถึงข้อมูลของผู้ป่วยที่ได้รับมอบหมายเพื่อการติดตามและดูแลตามสิทธิ์
        ผู้ดูแลระบบ (Admin) — เข้าถึงข้อมูลตามหน้าที่ในการบริหารระบบและการตรวจสอบความปลอดภัย

        🔎 ใช้ข้อมูลเพื่ออะไร

        • ให้บริการบันทึกและติดตามข้อมูลสุขภาพตามที่ระบบออกแบบไว้
        • แสดงข้อมูลให้ทีมดูแลที่ได้รับมอบหมาย
        • จัดทำประวัติ/รายงาน และแจ้งเตือนที่เกี่ยวข้องกับการดูแล
        • รักษาความถูกต้อง ตรวจสอบย้อนหลัง และรักษาความปลอดภัยของระบบ
        การให้ความยินยอมจะถูกบันทึกพร้อมเวอร์ชันเอกสารและเวลาที่ให้ความยินยอม หากมีการเปลี่ยนแปลงสาระสำคัญ ระบบสามารถขอให้ยืนยันใหม่ได้
        หมายเหตุ: หน้าจอนี้เป็นกลไกทางเทคนิคสำหรับการรับทราบและบันทึกความยินยอม ไม่ใช่คำรับรองว่าระบบปฏิบัติตามกฎหมายครบถ้วนทุกประการ ผู้ควบคุมข้อมูลควรตรวจ Privacy Notice, ฐานการประมวลผล, ระยะเวลาเก็บรักษา และช่องทางใช้สิทธิให้สอดคล้องกับการใช้งานจริง
